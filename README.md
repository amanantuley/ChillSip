## 📖 Overview

**ChillSip** is a modern web application designed to provide users with an engaging beverage browsing experience. Built using **Next.js**, **TypeScript**, **Firebase**, and **Tailwind CSS**, the project focuses on delivering a fast, responsive, and visually appealing interface.

The project demonstrates modern frontend development practices including server-side rendering, responsive UI design, reusable components, and scalable project architecture.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/amanantuley/ChillSip.git
```

Move into the project directory

```bash
cd ChillSip
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open your browser

```
http://localhost:3000
```
